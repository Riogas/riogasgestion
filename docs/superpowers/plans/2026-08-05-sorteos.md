# Sorteos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Módulo "Sorteos" en Goya: admin `/dashboard/sorteos` (crear sorteos, generar lotes de QRs, ZIP de PNGs, gestión de ganadores) + página pública `/sorteo` sin login donde el participante confirma sus datos y sabe si ganó (mecánica de momentos ganadores).

**Architecture:** Módulo NestJS `sorteos` con dos controllers (admin con AuthGuard; público con API-key interna + throttler) sobre 5 tablas Prisma nuevas. Lo público entra por route handlers Next dedicados (`/api/sorteo-publico/*`) que agregan la `x-api-key`; el código del QR viaja en cookie httpOnly (nunca visible en URL). Spec completo: `docs/superpowers/specs/2026-08-05-sorteos-design.md`.

**Tech Stack:** Next 16 App Router + NestJS 11 + Prisma 6 + Postgres goya. Nuevas deps: `qrcode`, `archiver`, `@nestjs/throttler`, `geoip-lite` (backend); `canvas-confetti` (front).

## Global Constraints

- Convención Prisma del repo: modelo PascalCase español, tabla `@@map` snake_case, campos camelCase sin `@map` por columna, `@db.VarChar(n)`. Migraciones = `npm run prisma:push` + `prisma:generate` (NO hay carpeta migrations).
- Backend: prefijo global `api`, puerto `PORT||3001`; endpoints protegidos = `@ApiBearerAuth()` + `@UseGuards(AuthGuard)` (`backend/src/common/guards/auth.guard.ts`); ValidationPipe global whitelist+forbidNonWhitelisted+transform ya configurado.
- Front admin: cadena componente → hook react-query (`src/hooks/sorteos/`) → service (`src/services/sorteos.ts`, axios `api` de `src/lib/axios.ts`) → catch-all `/api/[...path]` → Nest. Params de hooks **memoizados** (gotcha `useClientes.ts`: refetch infinito).
- Página pública FUERA de `src/app/dashboard/` (sin Sidebar/Navbar), tema claro fijo, marca RioGas (azul `#1E5BB8`, naranja `#FF7A1A`, fondo `public/backgroundgoya.png`, tipografía Geist), `prefers-reduced-motion` respetado.

- Respuestas públicas jamás revelan stock de premios, momentos, ni si un teléfono ya ganó.
- Zona horaria de negocio: día calendario **America/Montevideo** (UTC-3, sin DST).
- Env nuevas: `SORTEOS_PUBLIC_API_KEY` (backend y front), `SORTEOS_PUBLIC_BASE_URL` (backend, ej. `https://goya.riogas.com.uy`).

```ts
import * as crypto from 'crypto';

export const CODIGO_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
export const CODIGO_REGEX = /^[ABCDEFGHJKMNPQRSTUVWXYZ23456789]{12}$/;

export function generarCodigo(len = 12): string {
  let out = '';
  for (let i = 0; i < len; i++) out += CODIGO_ALPHABET[crypto.randomInt(CODIGO_ALPHABET.length)];
  return out;
}

export function formatearCanje(raw: string): string {
  return `${raw.slice(0, 4)}-${raw.slice(4, 8)}`;
}

export function generarMomentos(cantidad: number, desde: Date, hasta: Date): Date[] {
  const span = hasta.getTime() - desde.getTime();
  const momentos = Array.from({ length: cantidad }, () => new Date(desde.getTime() + crypto.randomInt(0, Math.max(1, span))));
  return momentos.sort((a, b) => a.getTime() - b.getTime());
}

// Uruguay no tiene DST desde 2015: offset fijo UTC-3.
const MVD_OFFSET_MS = 3 * 60 * 60 * 1000;
export function inicioDiaMontevideo(ahora: Date): Date {
  const local = new Date(ahora.getTime() - MVD_OFFSET_MS);
  return new Date(Date.UTC(local.getUTCFullYear(), local.getUTCMonth(), local.getUTCDate()) + MVD_OFFSET_MS);
}
```

Nota: `crypto.randomInt(0, max)` con max > 2^48 falla — span de un sorteo (semanas) está muy por debajo. Si `span === 0`, todos los momentos = desde.

**Reglas de `participar` (transacción `this.prisma.$transaction`):**
1. `findUnique` código (include sorteo). Sin match o regex inválida → `invalido`.
2. Sorteo `borrador`/`cancelado` o `now < fechaDesde` → `no_iniciado`; `estado === 'finalizado'` o `now > fechaHasta` → `finalizado`; código `estado !== 'disponible'` → `usado`; `edad < sorteo.edadMinima` → `edad_invalida`.
3. Límite: `count` participaciones de `deviceId` en el sorteo con `createdAt >= inicioDiaMontevideo(now)` ≥ `maxRegistrosDispositivoDia` → `limite_dispositivo`.
4. Consumo atómico del código: `updateMany({ where: { id, estado: 'disponible' }, data: { estado: 'usado', usadoAt: now } })`; `count === 0` → `usado` (carrera).
5. Crear participación (teléfono normalizado: solo dígitos, sin +598 → formato local `09XXXXXXX`); geo IP (`geoip-lite`, no-fatal) y reverse Nominatim si hay gps (no-fatal, ver Task 5) — ambos rellenan campos invisibles; `geoFuente = gps ? 'gps' : (ipPais ? 'ip' : null)`.
6. Premio: si el teléfono NO tiene otra participación `ganador: true` en el sorteo → `findFirst` momento con `participacionId: null` y `fechaMomento <= now` ordenado `fechaMomento asc`; claim atómico `updateMany({ where: { id: momento.id, participacionId: null }, data: { participacionId } })`; si `count === 1` → update participación `{ ganador: true, codigoCanje: formatearCanje(generarCodigo(8)) }` → `{ resultado: 'ganador', codigoCanje }`. Cualquier otro camino → `{ resultado: 'sigue' }`.
